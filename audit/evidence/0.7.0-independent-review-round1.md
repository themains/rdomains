2. **[P2] Explicitly incomplete provider responses can become successful classifications.** Location: `R/llm.R:172–182`, following the ellmer call above.

   The new path checks vocabulary membership but loses completion status. This regresses the previous completion checks and contradicts the package’s treatment of incomplete responses as `invalid_response`. [OpenAI’s structured-output documentation](https://developers.openai.com/api/docs/guides/structured-outputs) explicitly handles incomplete responses separately.
